# Practice notes: running the framework for real

A log of what worked and what didn't when the framework met a real campaign (QCobro round 1,
started 2026-09-16 with `/ps:ads new`). This is the evidence for the psstack port: each gap lists
what to change and where.

## Gaps found

| #   | Where it showed up               | Gap                                                                                                                                                                                                                                                                                                                                         | Proposed fix (for the port)                                                                                                                                                                                                                                                                              |
| :-- | :------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `/ps:ads new` order              | The wizard asks objective → audience → money → creative. Direction ("what kind of ads") has to come first, because it decides format, production cost and even whether a video budget makes sense.                                                                                                                                          | Add **Batch 0 · Direction** (voice, angles, image carrier, qualifier, AI imagery), and write the result to a round brief before any settings.                                                                                                                                                            |
| 2   | Setup                            | Setup doesn't check that the Pixel, the Page, the Instagram account and the payment method all belong to the **same** ad account. Here the Pixel was in a business account with no card and no Page.                                                                                                                                        | Add an "account readiness" table to setup: Pixel owner, Page linked, IG linked, payment method, events fired. Block `Create`, not direction.                                                                                                                                                             |
| 3   | Setup                            | The advertiser Page can differ from the product brand (Fonoster Page, QCobro product). The skill assumes they match.                                                                                                                                                                                                                        | Ask which Page speaks. If it differs, add the product and company to the primary text ("QCobro, de Fonoster").                                                                                                                                                                                           |
| 4   | Destination                      | Nothing checks that the landing page offers what the ad promises. The live site offered "demo gratis"; the ads promise the pilot.                                                                                                                                                                                                           | Add a **message-match check**: fetch the landing page, confirm the offer and the conversion event exist, then decide launch timing.                                                                                                                                                                      |
| 5   | `naming.md`                      | No `offer` angle key, though an offer-led ad is a standard B2B angle.                                                                                                                                                                                                                                                                       | Add `offer` to the angle library and naming grammar.                                                                                                                                                                                                                                                     |
| 6   | `placements.md` vs `CANVASES.md` | Preset names differ (`feed45`/`story916` at 1080 vs `feed-4x5`/`vertical-9x16` at 1440).                                                                                                                                                                                                                                                    | Replace `placements.md` with the framework canvases; keep one name set.                                                                                                                                                                                                                                  |
| 7   | Pencil                           | `execute` silently targets the active editor when the `filePath` isn't open; a separate `.pen` must be opened in Pen.app first. Pen.app doesn't flush to disk until saved.                                                                                                                                                                  | Document in the `creative` step: open the file, verify with `get_app_state`, check mtime before committing.                                                                                                                                                                                              |
| 8   | Pencil export                    | Exporting in the same `execute` call that built the frame captured half-rendered frames.                                                                                                                                                                                                                                                    | Already in `CANVASES.md` → Export step 0; carry into the skill.                                                                                                                                                                                                                                          |
| 9   | Direction                        | Direction never asked **how aware the audience is of the brand**. For an unknown brand in a cold audience, the offer-first and proof-first drafts failed review: "most people do not know what QCobro is".                                                                                                                                  | Add an awareness question to Batch 0 (unaware / category-aware / brand-aware). Unaware ⇒ every ad leads with the category line; offers come later in the funnel.                                                                                                                                         |
| 10  | Direction                        | "Match the website look" was accepted on paper but rejected on sight: editorial layouts and product widgets don't stop a thumb. The question was answered without seeing options.                                                                                                                                                           | Show 3–4 rough visual concepts **before** locking the look (photo-led, bold type, product UI), and ask with images, not descriptions.                                                                                                                                                                    |
| 11  | Templates                        | The slot layout (call-out, headline, sub, proof box, wordmark) only fits proof-style ads. Full-bleed photo with text on a scrim, and bold type with a 3D background, had to be built by hand.                                                                                                                                               | Add `tpl/photo-overlay` (full-bleed image, scrim, headline top or bottom, pill) and `tpl/bold-type` (fill or art background, huge headline, pill) for every canvas.                                                                                                                                      |
| 12  | AI imagery                       | The first people photo was rejected as "looks like a stock photo"; another setting read as a colmado, not an office; dates and religious images slipped into backgrounds.                                                                                                                                                                   | Add prompt rules to GUARDRAILS: candid, not posing, film grain, imperfect framing, name the setting explicitly (financiera office: counter with glass partition, filing cabinets), and list forbidden background items (calendars, dates, religious images, products on shelves).                        |
| 13  | Icons                            | Emoji export as outlines, and thin line icons are too weak to stop the scroll.                                                                                                                                                                                                                                                              | Use generated 3D art (as the background, with an empty text zone) for icon-led ads.                                                                                                                                                                                                                      |
| 14  | Brand layer                      | Loud ad colors (lime, bright green) were liked but rejected for not matching the landing page: "when people land on our website it seems cohesive".                                                                                                                                                                                         | The brand layer must define the ad palette **from the site's tokens** (dark and light mood), and GUARDRAILS should forbid off-palette colors in both the layout and generated art prompts.                                                                                                               |
| 15  | Copy × image                     | "Cobranzas automatizadas con Voz IA" over a photo of a person implies the person is the AI.                                                                                                                                                                                                                                                 | Add a congruence check to GUARDRAILS: an automation or AI claim needs an image with no person or a clearly artificial avatar; photos of people take augmentation copy ("su equipo, ahora con…").                                                                                                         |
| 16  | Safe-zone check                  | The self-check looked only at layout nodes (text, pill, icons) and missed two real violations: a wordmark outside the 4:5 → 1:1 crop, and a generated face whose chin sat in the 9:16 bottom band. Pedro caught it.                                                                                                                         | Make the check two-part and mandatory: (1) script the bounds of every text/icon/pill node against the canvas rules; (2) export each frame **with the guide visible** and inspect faces and subjects inside photos. Prompt generated images with explicit vertical bands for the face.                    |
| 17  | Upload                           | `ads_creative_upload_media` with `LOCAL_FILE` can't open its picker in a terminal client, and the skill's fallbacks were a public URL or a manual Ads Manager upload.                                                                                                                                                                       | Use `ads_creative_upload_local_image` (size + SHA-256) → POST the bytes to the returned `upload_url` with `Authorization`, `offset: 0`, `X-Entity-Name`, `X-Entity-Length`, `X-Entity-Type`, `file_size` → `ads_finalize_local_ad_image_upload`. Worked for all 6 assets.                                |
| 18  | Export format                    | Meta rejected Pencil's 8-bit **RGBA** PNG ("Invalid image format").                                                                                                                                                                                                                                                                         | Deliver ad images as JPEG (quality ~92, no alpha): smaller too (~0.3–0.6 MB vs 2–5 MB). Add the conversion to CANVASES → Export.                                                                                                                                                                         |
| 19  | Creative                         | The connector's `ads_create_creative` supports placement asset customization only for **video** (`placement_videos`); image ads can't carry the 9:16 variant.                                                                                                                                                                               | Either attach 9:16 manually in Ads Manager, or check if `degrees_of_freedom_spec`/asset feeds allow it and document the path.                                                                                                                                                                            |
| 20  | Create                           | Meta refuses to create **ads** (even PAUSED) without a payment method on the ad account (error 1359188); campaigns, ad sets, image uploads and creatives work without one. A missing Page also blocks creatives.                                                                                                                            | Add payment method and Page to the setup readiness table as blockers for the ad step, and build everything else first so the gap is one call per ad.                                                                                                                                                     |
| 21  | Build path                       | Ads Manager (UI) can save **draft ads without a payment method**, and it supports per-placement image customization (4:5 feeds, 9:16 Stories/Reels/Status, 1:1 crop) that the API connector can't do for images.                                                                                                                            | For image ads, build the final ads as Ads Manager drafts (browser), or use the API only when no 9:16 variant exists. Stop at "Publish".                                                                                                                                                                  |
| 22  | Hidden defaults                  | A new UI ad turned ON by default: Multi-advertiser ads, Website highlights, Visual touch-ups, Add music, Adapt multi-image, Add animation, Flex media, Add overlays, Text improvements, Brightness/contrast, Show spotlights, Relevant comments. Duplicating an ad pre-checks "Add music to Reels". Some confirm dialogs push to keep them. | Add a UI checklist to GUARDRAILS §4 with these exact names and where they live (Creative setup extensions, Enhancements step, Advanced preview → Essential enhancements, format Multi-advertiser checkbox, duplicate dialog). Verify visually: the accessibility tree reported wrong toggle states once. |
| 23  | AI disclosure                    | The Ads Manager UI has no AI-disclosure field for non-political ads; only the API's `self_ai_disclosure` exists (applies in EU, India, Taiwan, California, New York).                                                                                                                                                                       | Note in GUARDRAILS §3 that UI-built ads can't carry the flag; for audiences in those regions, build via API or check if Meta adds the field.                                                                                                                                                             |

## What worked

- One-question-at-a-time direction produced decisions in minutes and surfaced a user correction
  (static only) that a batched form would have buried.
- The templates' named slots made new ads a copy + fill job: the pain ad went from template to
  filled frames in one call.
- Guardrail copy limits turned drafting into a check: all three ads passed first time.
