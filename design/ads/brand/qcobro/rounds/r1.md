## What round 1 tests

**One variable: the message (angle).** Three static ads, each shipped as the minimum set
(`feed-4x5` + `vertical-9x16`), in one broad ad set, so Meta's delivery shows which message pulls
pilot requests.

| Ad  | Angle   | Message (working headline)           | Image carrier                                                                             | AI disclosure      |
| :-- | :------ | :----------------------------------- | :---------------------------------------------------------------------------------------- | :----------------- |
| 1   | `offer` | "15 días. 300 cuentas. Gratis."      | Product UI: gestión record (header + outcome rows)                                        | No                 |
| 2   | `proof` | "Cada llamada, a la vista."          | Product UI: gestión record (transcript + outcome rows)                                    | No                 |
| 3   | `pain`  | "Más cuentas que manos para cobrar." | **Photo**: AI-generated, realistic small Dominican collections office, no readable brands | **Yes** (`OPT_IN`) |

Known confound: ad 3 changes both the angle and the image type (photo vs UI). Accepted on purpose,
because a capacity message shown on UI doesn't show the problem. If ad 3 wins, round 2 separates
the two.

## Decisions

| Decision            | Choice                                                               | Why                                                                               |
| :------------------ | :------------------------------------------------------------------- | :-------------------------------------------------------------------------------- |
| Format              | Static only                                                          | Fastest to produce and judge; the call Reel waits for a real anonymized recording |
| Voice               | The image and headline carry it; no founder video, no AI-agent pitch | Follows from static-only                                                          |
| Call-out            | Role only: `PARA FINANCIERAS Y EQUIPOS DE COBRO`                     | More reach; qualification happens after the click (screen pilot requests)         |
| Pain photo source   | AI-generated, realistic                                              | On-brief DR look; disclosure accepted                                             |
| Not used in round 1 | Public-prices contrast angle, testimonials, video, carousel          | Prices angle kept for a later round                                               |

## Competitive context (Ad Library, 2026-09-16)

Almost no collections-software advertisers reach the DR. Kleva runs generic performance copy;
a Peruvian collections system runs feature-list ads. Nothing leads with calls, transparency or a
free pilot, so all three angles are uncontested.
